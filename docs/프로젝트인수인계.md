# 프로젝트 인수인계

## 새 세션에서 시작하는 방법

이 저장소를 작업 폴더로 연 새 Codex 세션은 루트 `AGENTS.md`에서 현재 맥락을 자동으로 확인할 수 있다. 따라서 지금까지의 대화를 다시 설명할 필요가 없다.

새 세션의 첫 요청은 다음처럼 바로 작업 내용만 말하면 된다.

> 이 프로젝트에서 관리자 대시보드의 알림 필터를 개선해줘. 루트 AGENTS.md와 docs 문서를 기준으로 현재 구조를 확인하고 구현·검증해줘.

만약 사용하는 도구가 `AGENTS.md`를 자동으로 읽지 않는다면 다음 한 문장만 먼저 전달한다.

> 작업 전에 루트 AGENTS.md, docs/기능명세서.md, docs/시스템동작설명서.md, docs/프로젝트인수인계.md를 읽고 기존 결정사항을 유지해줘.

## 현재 제품 상태

자립동행은 로컬에서 실제 프런트엔드와 백엔드가 함께 실행되는 MVP다. Figma Make 시안의 색상과 컴포넌트 감각은 유지하되, 시안용 화면 전환 상단바는 제거했다.

참고 Figma Make: <https://www.figma.com/make/v9dwYzJTQClOwGfIvY9dc5/Social-Impact-Service-UI-UX--%EB%B3%B5%EC%82%AC->

현재 시작 화면은 통합 로그인이다.

- 청년 선택: 로그인 후 오늘의 안부 설문, 제출 완료, 응답 수정 또는 종료
- 전담요원 선택: 로그인 후 담당 청년 현황, 상태 검색·필터, 알림 센터, 청년 상세, 재분석, 처리 상태·메모 저장

프런트엔드의 주요 데이터는 모두 `/api`를 통해 FastAPI에서 가져온다. 서버는 JSON 파일에 데이터를 실제로 저장하며 재시작 후에도 유지한다.

## 중요한 최신 결정

1. 화면 상단에 청년용/관리자용/상세 화면을 직접 바꾸는 데모 내비게이션을 두지 않는다.
2. 사용자 역할은 로그인 화면에서 선택한다.
3. 역할별 실제 서비스 흐름을 유지한다.
4. Python `manage.py`를 단일 실행 관리 도구로 사용한다.
5. BAT 파일은 PowerShell이 아닌 Python을 호출한다.
6. `.ps1` 파일은 모두 삭제된 상태다.
7. JSON 저장소와 데모 인증은 향후 DB·외부 인증으로 교체할 수 있는 인터페이스 뒤에 둔다.
8. AI 분석 실패는 사용자 업무 흐름을 중단시키지 않고 규칙 분석으로 폴백한다.

## 소스 우선순위

새 요청을 해석할 때 다음 순서로 판단한다.

1. 현재 사용자의 명시적 요청
2. 루트 `AGENTS.md`의 유지해야 할 결정
3. `docs/기능명세서.md`의 F1~F7 범위
4. `docs/시스템동작설명서.md`의 실제 구현 설명
5. 로컬 Figma Make 소스의 디자인 토큰과 기존 컴포넌트

문서와 코드가 다르면 코드를 확인해 실제 동작을 검증하고, 작업 중 문서를 함께 바로잡는다.
