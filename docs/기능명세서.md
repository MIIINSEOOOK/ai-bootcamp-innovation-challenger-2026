# 자립준비청년 안전망 훼손 감지 AI 에이전트 — 기능명세서 (MVP)

## 0\. 서비스 한 줄 설명

자립준비청년의 일상 응답 데이터를 지속적으로 분석하여 사회적 안전망의 훼손 가능성(지원·관계 공백)을 조기에 발견하고, 자립지원전담요원에게 확인이 필요한 대상을 선별해 알려주는 웹 기반 AI 에이전트.

## 1\. 사용자별 역할

|사용자|역할|
|-|-|
|자립준비청년|매일 안부 메시지에 응답, 자신의 상태를 시스템에 남김|
|전담요원|담당 청년 목록/상태 확인, AI 알림 검토, 최종 판단 및 개입(연락/방문 등) 수행|
|AI|응답 패턴 변화를 분석해 "지원 공백 가능성"을 탐지하고 근거와 함께 전담요원에게 전달|

## 2\. 핵심 사용자 흐름

**청년 측**
오늘의 안부 메시지 수신 (휴대폰 알림, 메일 알림, 위젯 알림 등) → 응답(텍스트/버튼) → 응답 데이터 저장

**전담요원 측**
로그인 → 담당 청년 목록 확인 → 청년별 응답 이력/AI 분석 결과 확인 → (이상 감지 시) 알림 확인 → AI 판단 근거 검토 → 처리 상태 기록(확인완료/연락필요/관찰지속)

## 3\. MVP 구현 기능

### \[F1] 오늘의 안부 메시지 발송

**목적:** 전담요원의 일상적 안부 확인 부담을 자동화하고, 시스템이 능동적으로 접촉을 시도한다.
**사용자:** 청년 / 시스템
**입력:** 발송 대상 청년 목록, 발송 시각(스케줄), 메시지 템플릿
**AI 처리:** 없음(정해진 템플릿 발송). MVP에서는 외부 카카오톡/문자 연동 대신 모의 메시지 UI로 구현.
**출력:** 청년 화면에 오늘의 안부 메시지 카드 노출
**사용자 행동:** 청년이 메시지를 확인
**MVP 구현 여부:** 구현

### \[F2] 청년 응답 입력

**목적:** 응답 여부·내용·시간을 수집해 이후 분석의 원천 데이터로 사용한다.
**사용자:** 청년
**입력:** 텍스트 응답 또는 버튼 선택(예: 좋음/보통/힘듦), 응답 시각
**AI 처리:** 없음(원시 데이터 수집만)
**출력:** 응답 완료 화면
**사용자 행동:** 응답 제출, 필요 시 자유 텍스트 추가 입력
**MVP 구현 여부:** 구현

### \[F3] 응답 데이터 축적 및 시뮬레이션

**목적:** 시간에 따른 응답 패턴 변화를 분석할 수 있도록 데이터를 누적한다.
**사용자:** 시스템
**입력:** 발송 여부, 응답 여부, 응답까지 걸린 시간, 응답 내용, 날짜
**AI 처리:** 없음(저장 및 집계: 기간별 응답률, 최근 응답률 변화, 연속 미응답 일수 계산)
**출력:** 청년별 응답 이력 테이블/그래프용 데이터
**사용자 행동:** 없음(자동 축적). MVP에서는 실제 장기 데이터 대신 청년별 샘플/가상 데이터 세트(정상형·악화형 등 시나리오)를 미리 구성해 시연.
**MVP 구현 여부:** 구현

### \[F4] AI 기반 안전망 상태 분석

**목적:** 축적된 응답 데이터를 근거로 현재 안전망 상태(정상/관심 필요/훼손 의심)를 판단하고, 반드시 판단 근거를 함께 제시.
**사용자:** AI
**입력:** 청년별 응답 이력(응답률, 응답률 변화, 연속 미응답 일수, 응답 내용 변화), 기본 자립상태 정보(주거/취업 등 프로필)
**AI 처리:** 응답 빈도·미응답 지속·이전 대비 변화·응답 내용 변화·자립상태 정보를 종합해 3단계(정상/관심 필요/안전망 훼손 의심)로 분류하고, 판단에 사용된 구체적 수치·근거 문장을 생성. 자살 위험·정신질환 등 진단은 수행하지 않으며, 위험등급을 청년에게 직접 부여하지 않고 "확인이 필요한 상태 변화"만 탐지.
**출력:** 상태 라벨, 근거 텍스트(예: "최근 7일 응답률 86%→29%로 감소, 3일 연속 미응답"), 최근 응답 추이 그래프
**사용자 행동:** 전담요원이 결과를 열람
**MVP 구현 여부:** 구현

### \[F5] 전담요원 알림

**목적:** 안전망 훼손 가능성이 감지된 청년을 전담요원이 즉시 인지하도록 한다.
**사용자:** 전담요원
**입력:** F4의 분석 결과(상태, 근거, 추이, 마지막 응답 시점)
**AI 처리:** 없음(F4 결과를 알림 형식으로 구성)
**출력:** 관리 화면 알림 목록에 대상자/상태/근거/최근 추이/마지막 응답 시점 카드 표시
**사용자 행동:** 알림 클릭 → 상세 근거 확인 → 처리 상태 선택(확인 완료 / 연락 필요 / 관찰 지속) 및 메모 입력
**MVP 구현 여부:** 구현

### \[F6] 전담요원 로그인 및 담당 청년 목록

**목적:** 전담요원이 자신이 담당하는 청년들의 현황을 한눈에 파악한다.
**사용자:** 전담요원
**입력:** 로그인 정보(MVP는 간단 인증으로 대체 가능)
**AI 처리:** 없음
**출력:** 담당 청년 목록(이름, 현재 상태 라벨, 마지막 응답일, 알림 유무를 색상/뱃지로 구분)
**사용자 행동:** 목록에서 청년 선택 → 상세 화면 진입
**MVP 구현 여부:** 구현

### \[F7] 청년 상세 화면

**목적:** 개별 청년의 응답 이력과 AI 분석 결과를 상세히 확인한다.
**사용자:** 전담요원
**입력:** 선택된 청년 ID
**AI 처리:** 없음(F3, F4 결과 조회)
**출력:** 기본 프로필, 응답률 추이 그래프, 최근 응답 로그, AI 판단 근거, 과거 처리 이력
**사용자 행동:** 처리 상태 업데이트, 메모 작성
**MVP 구현 여부:** 구현

## 4\. MVP 미구현 (향후 확장 기능)

### \[F8] 사례관리 서류 작성 자동화

상담기록·자립계획·서비스제공계획 등의 초안을 AI가 기존 상담 기록과 자립상태 정보로부터 자동 생성. MVP 미구현, 향후 확장 제안.

### \[F9] 자립 지원 제도 정보 수집 및 매칭

청년의 상태·욕구(경제/주거/취업/교육/관계)를 분석해 정부·지자체·민간 지원제도를 탐색하고 연계할 지원 제도 후보를 전담요원에게 제시. 외부 크롤링·DB 구축 등의 복잡성을 이유로 MVP 미구현.

## 5\. 필요한 데이터 항목

* 청년 기본 정보: 이름(또는 ID), 담당 전담요원, 자립상태 정보(주거/취업/교육 등 기본 프로필)
* 안부 메시지 로그: 발송 일시, 메시지 내용
* 응답 로그: 응답 여부, 응답 일시, 응답까지 걸린 시간, 응답 내용(텍스트/버튼 선택)
* 집계 지표: 기간별 응답률, 응답률 변화율, 연속 미응답 일수
* AI 분석 결과: 상태 라벨(정상/관심 필요/훼손 의심), 판단 근거 텍스트, 분석 시각
* 전담요원 처리 이력: 처리 상태(확인완료/연락필요/관찰지속), 메모, 처리 일시

## 6\. AI가 담당하는 핵심 처리

AI의 역할은 단순 챗봇이나 감정분석이 아니라, **청년의 시간에 따른 상호작용 데이터(응답률·응답 패턴·미응답 지속 등)를 분석해 사회적 안전망의 변화와 지원 공백 가능성을 발견하고, 전담요원의 개입이 필요한 대상을 선별하는 것**이다. 즉 F3(데이터 집계)과 F4(상태 분류 및 근거 생성)가 AI의 핵심 처리 범위이다.

## 7\. 전담요원이 최종적으로 판단하는 부분

* AI가 제시한 "관심 필요/안전망 훼손 의심" 상태가 실제로 개입이 필요한 상황인지 여부
* 연락, 방문, 자원 연계 등 구체적 개입 방식과 시행 여부
* 알림에 대한 처리 상태(확인완료/연락필요/관찰지속) 기록
* AI는 진단·위험등급 부여를 하지 않으며, 모든 실제 판단과 개입은 전담요원이 수행한다.

## 8\. 화면별 주요 UI 요소

**청년 화면**

* 오늘의 안부 메시지 카드
* 응답 입력(버튼 선택 + 자유 텍스트)
* 응답 완료 표시

**전담요원 화면**

* 로그인 화면
* 담당 청년 목록(상태 뱃지, 알림 표시, 마지막 응답일 정렬/필터)
* 알림 목록(대상자, 상태, 근거 요약, 마지막 응답 시점)
* 청년 상세 화면(프로필, 응답률 추이 그래프, 응답 로그, AI 판단 근거 상세, 처리 상태 선택 UI, 메모 입력)

## 9\. 개발 범위 관련 참고

* F1\~F7만 구현하고 F8\~F9는 문서상 향후 확장 계획으로만 남긴다.
* 외부 메시지 API(카카오톡/문자) 연동은 필수가 아니며 모의 UI로 대체 가능.
* 장기간 실데이터 확보가 불가능하므로 청년별 시나리오(정상 유지형, 점진적 악화형, 급격한 단절형 등) 샘플 데이터를 미리 구성해 AI 분석 결과를 시연한다.
