# 자립준비청년 안전망 훼손 감지 AI 에이전트

AI 부트캠프 이노베이션 챌린저 2026 프로젝트

## 소개
자립준비청년의 일상 응답 데이터를 지속적으로 분석하여 사회적 안전망의 훼손 가능성(지원·관계 공백)을 조기에 발견하고, 자립지원전담요원에게 확인이 필요한 대상을 선별해 알려주는 웹 기반 AI 에이전트입니다.

- 상세 기능 명세: [docs/기능명세서.md](docs/기능명세서.md)
- 디자인: [Figma](https://www.figma.com/make/fO9eDc6r1ote2DwQ2FsyzD/Social-Impact-Service-UI-UX)

## 사용자
- **자립준비청년**: 매일 안부 메시지에 응답, 자신의 상태를 시스템에 남김
- **전담요원**: 담당 청년 목록/상태 확인, AI 알림 검토, 최종 판단 및 개입 수행
- **AI**: 응답 패턴 변화를 분석해 지원 공백 가능성을 탐지하고 근거와 함께 전담요원에게 전달
